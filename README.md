## Deskripsi

Aplikasi dashboard desktop berbasis PySide6 untuk memantau nilai mahasiswa per jurusan dan mata kuliah. Dibuat dengan color palette pink dan struktur kode terpisah per file (Separation of Concerns).

## Fitur

- Filter data berdasarkan jurusan
- Pilihan chart: Bar Chart, Line Chart, Pie Chart
- KPI cards: rata-rata nilai, jumlah mahasiswa, persentase lulus, nilai tertinggi
- Tabel lengkap dengan kolom Grade (A–E) dan warna baris otomatis
- Chart rata-rata nilai per mata kuliah


## Library

| Library | Peran |
|---|---|
| PySide6 | GUI desktop |
| Matplotlib | Grafik / chart |
| Pandas | Baca dan olah CSV |
